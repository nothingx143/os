# Q016: File Allocation (Level 1 Challenge 16)

## Verified Solution (`Q016.c`)

```c
#include <stdio.h>

int n, i, x, cur, top, st[1005];

#define SOLVE cur=1; top=0; \
    for(i=0;i<n;i++) { \
        scanf("%d", &x); \
        while(top > 0 && st[top-1] == cur) { top--; cur++; } \
        if(x == cur) cur++; else st[top++] = x; \
    } \
    while(top > 0 && st[top-1] == cur) { top--; cur++; } \
    if(cur == n+1) puts("sequential"); else puts("not sequential");

int main() {
    while(scanf("%d", &n) == 1 && n > 0) {
        SOLVE
    }
    return 0;
}
```

## Problem Statement

The kamali is on vacation in the beautiful country of Chefville. The island is a narrow strip of land running from north to south. A single road from north to south connects all the villages in the country. There, he observed, the postal services works in a very curious way. There is a postman for every village. In the morning, say postman A, starts traveling to the North, disbursing all the mails on the way. When he meets another postman coming from the opposite direction on the way, say B, A hands over all the mails to B which are to be delivered to addresses that lie in the North and vice versa for B. Then both turn back and start traveling in the opposite directions... Now you find whether the given numbers can be arranged in sequential file allocation order or not.

(Classic Street Parade permutation stack check: Determine whether numbers $1 \dots N$ can be sorted in ascending order using a side street / LIFO stack).

### Input Format
Multiple test cases ending with `0`.  
For each test case:
- Line 1: Number of elements $N$
- Line 2: $N$ space-separated integers
- Final line: `0`

### Output Format
For each test case, print `sequential` if the elements can be reordered in increasing order, otherwise print `not sequential`.
