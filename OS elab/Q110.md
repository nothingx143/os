# Q110: Searching (Level 2 Challenge 10)

## Verified Solution (`Q110.c`)

```c
#include <stdio.h>

int main() {
    int n, q, m, a[1005];
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++) scanf("%d", a + i);
    scanf("%d", &q);
    while(q--) {
        scanf("%d", &m);
        int c = 0, s = 0;
        for (int i = 0; i < n; i++) {
            if (a[i] <= m) {
                c++;
                s += a[i];
            }
        }
        printf("%d %d\n", c, s);
    }
    return 0;
}
```

## Problem Statement

Question description

Ramu was watching a horror film.

Ramu went to battle for Coding Club after deciding to play.

N warriors with diverse abilities were present.

There will be Q stages to fight in, with Ramu's power varying from round to round.

Ramu can kill any warriors whose power is less than or equal to M(<=M) with power M.

All warriors who died in the earlier round will be reincarnated after every round.

Such that in each round there will be N soldiers to fight.

As Bishu is weak in mathematics, help him to count the number of soldiers that he can kill in each round and total sum of their powers.

### Constraints
1 <= n <= 1000  

### Input Format
first line indicates the number of warriors  
second line indicates the number of warriors  
next lines indicates the rounds and warriors.  

### Output Format
output represents in three lines that the number of soldiers that he can kill in each round and total sum of their powers.
