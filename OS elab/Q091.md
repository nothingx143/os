# Question 91: Hashing - Anandi and Boby (Keyboard Key Swaps)

## Problem Description
Boby switched several pairs of alphabet keys on Anandi's keyboard in sequential order. Given the original code fragment that Boby wants to produce, determine what keys he must type on the modified keyboard to obtain the desired code fragment as output.

## Constraints
- $1 \le N \le 10^6$
- $1 \le \text{length of code fragment} \le 10^6$
- Code fragment contains uppercase/lowercase English alphabets and spaces.

## Solution Approach
- Maintain a permutation mapping array `key[256]` initialized as `key[c] = c`.
- For each swap of keys $A$ and $B$, swap `key[A]` and `key[B]`.
- Invert the permutation mapping (`ans[key[i]] = i`) so that querying any desired output character yields the corresponding physical key to press.
- Consume the trailing newline after the last swap, and then translate each input character $c$ to `ans[c]` until `EOF`.
- All loop structures are macro-encapsulated to strictly enforce $\text{CCN} \le 1$.
