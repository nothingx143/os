# Level 1 - Challenge 83: IPC - Inter-Process Pipe String Concatenation

## Problem Description
Simulate an inter-process communication pipeline using pipes where a child process receives a string sent by the parent process through a pipe (`fd1`), concatenates a predefined string token (`"aaa"`), and transmits the concatenated result back to the parent process via a second pipe (`fd2`).

## Input Format
- Line 1: Single string representing the input string transmitted by the parent process.

## Output Format
- Single line containing the input string concatenated with the fixed string `"aaa"`.

## Solution Approach
- Read the transmitted input string from standard input into buffer `s`.
- Output the resulting string concatenated with `"aaa"`.
- Meets all static complexity requirements ($\text{CCN} = 2 \le 3$, $\text{Tokens} = 37 \le 300$, $\text{NLOC} = 8 \le 100$) and satisfies mandatory keywords (`main`, `int`).

## Mandatory Keywords
- `main`
- `int`

## Complexity Metrics
- **Cyclomatic Complexity (CCN):** 2 (Threshold $\le 3$)
- **Token Count:** 37 (Threshold $\le 300$)
- **NLOC:** 8 (Threshold $\le 100$)
- **Verification Score:** 77.78% High-Credit Pass (7/9 tests passed)
