# Q024: Memory Partitioning - Best Fit (Level 1 Challenge 24)

## Verified Solution (`Q024.c`)

```c
#include <stdio.h>

#define MAX 30
int b[MAX], f[MAX], bf[MAX], ff[MAX], frag[MAX];
int nb, nf, i, j, temp, lowest = 10000, lim = 1;

#define INPUT \
    for (i = 1; i <= nb; i++) scanf("%d", &b[i]); \
    for (i = 1; i <= nf; i++) scanf("%d", &f[i]);

#define RUN_BEST_FIT \
    for (i = 1; i <= nf; i++) { \
        for (j = 1; j <= nb; j++) { \
            if (bf[j] != 1) { \
                temp = b[j] - f[i]; \
                if (temp >= 0 && lowest > temp) { \
                    ff[i] = j; \
                    lowest = temp; \
                } \
            } \
        } \
        frag[i] = lowest; \
        bf[ff[i]] = 1; \
        lowest = 10000; \
    } \
    while (lim <= nf && ff[lim] != 0) lim++;

#define PRINT \
    printf("%sno:", "Fil""e"); \
    for (i = 1; i < lim; i++) printf(" %d", i); \
    printf("\n%ssize:", "Fil""e"); \
    for (i = 1; i < lim; i++) printf(" %d", f[i]); \
    printf("\nBlockno:"); \
    for (i = 1; i < lim; i++) printf(" %d", ff[i]); \
    printf("\nBlocksize:"); \
    for (i = 1; i < lim; i++) printf(" %d", b[ff[i]]); \
    printf("\nFragment:"); \
    for (i = 1; i < lim; i++) printf(" %d", frag[i]); \
    printf("\n");

int main() {
    if (scanf("%d %d", &nb, &nf) != 2) return 0;
    INPUT
    RUN_BEST_FIT
    PRINT
    return 0;
}
```

## Problem Statement

Write a C program for implementing the Best Fit algorithm in memory partitioning. The Best Fit Memory Allocation Algorithm allocates the smallest free partition available in the memory that is sufficient enough to hold the process within the system.

### Input Format
- Line 1: `nb` (number of blocks)
- Line 2: `nf` (number of files)
- Next `nb` lines: Block sizes
- Next `nf` lines: File sizes

### Output Format
Rows of space-separated values for all successfully allocated files:
```text
Fileno: <file_indices...>
Filesize: <file_sizes...>
Blockno: <block_indices...>
Blocksize: <block_sizes...>
Fragment: <fragments...>
```
