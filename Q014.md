## Problem Statement

Ruppa is an engineer assigned to build roads between the N towns of Evoland. Towns are assigned IDs from 1 to N. A road connects exactly one pair of towns, and is bidirectional. The mayor of Evoland allocated a very small budget for this project. Thus, Sarah is forced to build as few roads as possible while still keeping all N towns connected via roads. Note that this is an absolute requirement; any network not satisfying this will not be accepted by the mayor.

Simulate indexed file lookup: Read $n$ files with their allocated block lists. Given a query filename, output the filename, block count, and occupied blocks, or `File Not Found`.

### Input Format
- Line 1: Number of files $n$
- For each file:
  - Filename and block count
  - List of block numbers
- Last line: Query filename

### Output Format
```text
No.of blocks blocks occupied
<filename> <count> <blocks...>
```
or
```text
File Not Found
```
