# Level 1 Challenge 100: Dining Philosophers Process Synchronization

## Problem Description
There are 5 philosophers (A, B, C, D, E) seated at a round table for dinner:
- To complete dinner, each must acquire 2 forks (left fork, then right fork).
- Only 5 forks are available on the table.
- If all try to acquire forks simultaneously, circular wait and deadlock occur.
- Deadlock avoidance solution: The last philosopher (E) reverses acquisition order (tries right fork first, then left fork). Since fork 4 is already held by philosopher D, E waits without acquiring fork 5. This allows philosopher A to acquire fork 5 and complete dinner, cascading through all philosophers until all 5 finish.

The portal evaluates a deterministic 4-philosopher synchronization trace showing fork acquisitions, waiting states, fork releases, and cumulative completed counts.

## Input Format
Single integer indicating simulation run mode (`1` or `2`).

## Output Format
Full simulation execution trace showing:
- Initial fork acquisitions and waiting statuses
- Progression of philosophers completing dinner and releasing forks
- Cumulative count of philosophers who completed dinner at each phase
