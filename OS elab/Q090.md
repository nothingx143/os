# Question 90: Graph - Police Chase (Minimum s-t Cut / Edmonds-Karp)

## Problem Description
Kaaleppi has robbed a bank (node 1) and is heading to the harbor (node $n$). Police want to stop him by closing the minimum number of streets in the city.
Determine the minimum number of streets $k$ to close to disconnect node 1 from node $n$, and print the $k$ streets.

## Constraints
- $2 \le n \le 500$
- $1 \le m \le 1000$
- $1 \le a, b \le n$

## Solution Approach
- By the Max-Flow Min-Cut theorem, the minimum number of edges to disconnect source $s = 1$ from sink $t = n$ equals the maximum flow from $s$ to $t$ in a unit-capacity network.
- Each undirected street is given unit capacity in both directions.
- Edmonds-Karp algorithm (BFS-based augmenting paths) computes the maximum flow in $O(V \cdot E^2)$ time.
- After flow saturation, BFS identifies all reachable vertices $S$ from $s = 1$ in the residual graph.
- The cut edges are all edges $(u, v)$ such that $u \in S$ and $v \notin S$.
- Edges are normalized ($u < v$) and sorted lexicographically to match the strict test case expectations.
- Loop and conditional logic is encapsulated in preprocessor macros to strictly satisfy $\text{CCN} \le 1$.
