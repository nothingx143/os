# Level 1 - Challenge 62: Tree Traversals (Preorder and Inorder to Postorder)

## Problem Description
There are three common ways to traverse the nodes of a binary tree:
- **Preorder:** First process the root, then the left subtree, and finally the right subtree.
- **Inorder:** First process the left subtree, then the root, and finally the right subtree.
- **Postorder:** First process the left subtree, then the right subtree, and finally the root.

There is a binary tree of $n$ nodes with distinct labels. Given the preorder and inorder traversals of the tree, determine its postorder traversal.

## Constraints
- $1 \le n \le 10^5$
- Distinct node labels

## Input Format
- First line: integer $n$ (the number of nodes).
- Second line: $n$ integers describing the preorder traversal.
- Third line: $n$ integers describing the inorder traversal.

## Output Format
- Print the postorder traversal of the tree on a single line separated by spaces.

## Solution Approach
- Uses an iterative $O(N)$ tree construction algorithm with explicit stacks to completely eliminate recursion stack limits and handle trees of arbitrary depth ($N = 10^5$).
- Traverses the reconstructed tree iteratively to produce the postorder traversal in $O(N)$ time and space.

## Mandatory Keywords
- `for(i=1;i<=n;i++)`
