# Question 88: IPC - Three Way Communications (Transceivers Range)

## Problem Description
The Chef, head server, and sous-chef each carry a two-way transceiver with transmission range $R$. Two transceivers can communicate directly if their Euclidean distance is $\le R$. If two people cannot communicate directly, they can communicate via the third person if both are within range of the third.
Determine if it is possible for all three people to communicate with each other. Output `yes` or `no` for each test case.

## Constraints
- $1 \le T \le 100$
- $1 \le R \le 1000$
- $-1000 \le x, y \le 1000$

## Solution Approach
- In a triangle graph of 3 vertices, all 3 vertices form a single connected component if and only if there are at least 2 edges.
- Compute the squared Euclidean distances between the 3 pairs:
  - $(C, H)$, $(C, S)$, and $(H, S)$.
- If at least 2 pairs have distance squared $\le R^2$, output `yes`, otherwise `no`.
- Use 64-bit integers (`long long`) to eliminate any potential overflow on distance calculations.
