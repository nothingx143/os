# Q112: Sorting (Level 2 Challenge 12)

## Verified Solution (`Q112.c`)

```c
#include <stdio.h>
#include <stdlib.h>
#define L long long
#define G x[j+1]-x[j]

L x[200005], d[200005];

int k(const L*a,const L*b){return*a>*b?1:-1;}

int main() {
    L m, r, a;
    int j, cnt = 0;
    scanf("%lld%lld%lld", &m, &r, &a);
    for(j=1;j<=m;++j) scanf("%lld", x + j);
    qsort(x + 1, m, 8, (void*)k);
    for (j = 1; j < m; j++) if (G > a) d[cnt++] = (G - 1) / a;
    qsort(d, cnt, 8, (void*)k);
    m = cnt + 1;
    for (j = 0; j < cnt && r >= d[j]; j++) { r -= d[j]; m--; }
    printf("%lld\n", m);
}
```

## Problem Statement

Problem Description:
There are 'm' students numerated from 1 to m. The level of the j-th student is xj. You need to split the students into stable groups. A group of students is called stable, if in the sorted array of their levels no two neighboring elements differ by more than 'a'.

Apart from the 'm' given students, teachers can invite at most 'r' additional students with arbitrary levels (at professors' choice). Find the minimum number of stable groups professors can form from all students (including the newly invited).

### Constraints
1 <= m <= 200000  
0 <= r <= 10^18  
1 <= a <= 10^18  
1 <= xj <= 10^18  

### Input Format
The first line contains three integers m, r, a - the initial number of students, the number of students you can additionally invite, and the maximum allowed level difference.  
The second line contains 'm' integers x1, x2, ..., xm (1 <= xj <= 10^18) - the students levels.  

### Output Format
Print the output in a single lines contains, the minimum number of stable groups you can split the students into.
