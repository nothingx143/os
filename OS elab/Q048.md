# Challenge 48: Stack - Unique Max and Second-Max Pairs in Permutation Subarrays

## Verified Solution (`Q048.c`)

```c
#include <stdio.h>

int n, a[100005], stck[100005], top = -1;
long long ans = 0;

int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", a + i);
    for (int i = 0; i < n; i++) {
        while (top!=-1 && stck[top]<a[i]) {
            ans++;
            top--;
        }
        ans += (top != -1);
        stck[++top] = a[i];
    }
    printf("%lld\n", ans);
    return 0;
}
```

---

## Problem Description
Given a permutation of numbers from 1 to $N$. Among all the contiguous subarrays, find the number of unique pairs $(a, b)$ such that $a \neq b$ and $a$ is the maximum and $b$ is the second maximum in that subarray.

### Input Format
- First line contains an integer $N$ ($1 \le N \le 10^5$).
- Second line contains $N$ space-separated distinct integers $A_i$ ($1 \le A_i \le N$), denoting the permutation.

### Output Format
- Print the required answer (total count of unique max/second-max pairs).
