# Level 1 - Challenge 74: Optimal Page Replacement Simulation (Belady's Algorithm)

## Problem Description
Simulate Belady's Optimal Page Replacement algorithm. Given the number of frames $F$, the number of page references $N$, and the page reference string, track and display the frame memory contents after referencing each page and report the total page faults.

## Input Format
- Line 1: Integer $F$ (number of frames).
- Line 2: Integer $N$ (number of pages).
- Line 3: $N$ space-separated integers representing the page reference sequence.

## Output Format
- After each page reference, print the frame array elements separated by tabs (`\t`) with a trailing tab and newline.
- Finally, print `Total Page Faults = <count>`.

## Solution Approach
- Uses Belady's optimal page replacement algorithm:
  - When cache is not full (`fr[k] < 0`), fills empty frames sequentially from index 0.
  - On page hit, frame contents remain unchanged.
  - On page fault when cache is full, scans future references to find the page referenced furthest in the future (or never referenced again) and replaces that frame.
  - Tie-breaking among pages never referenced again prioritizes the lowest frame index.
- Implements a unified array search function `at()` for both cache lookup and future distance computation, minimizing cyclomatic complexity and token count.
