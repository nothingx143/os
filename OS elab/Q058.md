# Challenge 58: Page Replacement - First In First Out (FIFO) Page Replacement

## Problem Description
Write a program to implement First In First Out (FIFO) page replacement. The FIFO page replacement technique is one of the simplest page replacement algorithms to implement. It is a conservative, low-overhead algorithm that maintains a queue to keep track of all the pages in memory. When a page needs to be replaced, the page at the front of the queue (the oldest page in memory) is selected for removal.

### Input Format
- First line indicates the number of pages $N$.
- Second line indicates the sequence of $N$ space-separated page numbers.
- Third line indicates the number of memory frames $M$.

### Output Format
- Memory frame status after each page reference (unallocated frames represented by `-1`), with elements space-separated.
- Final line indicating total page faults: `Total Page Faults:<count>`.

## Solution (C)
```c
#include <stdio.h>

int frames[1005], pages[1005], m, n, k = 0, faults = 0;

int get_frame(int j) {
    return frames[j];
}

void display() {
    for (int j = 0; j < m; j++) printf("%d ", frames[j]);
    printf("\n");
}

int is_present(int p) {
    for (int j = 0; j < m; j++)
        if (frames[j] == p) return 1;
    return 0;
}

void step(int p) {
    if (!is_present(p)) {
        frames[k] = p;
        k = (k + 1) % m;
        faults++;
    }
    display();
}

int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &pages[i]);
    scanf("%d", &m);
    for (int j = 0; j < m; j++) frames[j] = -1;
    for (int i = 0; i < n; i++) step(pages[i]);
    printf("Total Page Faults:%d\n", faults);
    return 0;
}
```
