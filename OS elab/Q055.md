# Q055: Queue - Distinct Subsequences (Level 1 Challenge 55)

## Verified Solution (`Q055.c`)

```c
#include <stdio.h>

char cc[500005];
long long last[128];

int main() {
    scanf("%s", cc);
    long long total = 1, mod = 1000000007;
    int i;
    for(i=0;cc[i];i++) {
        long long cur = total;
        total = (total * 2 - last[(unsigned char)cc[i]] + mod) % mod;
        last[(unsigned char)cc[i]] = cur;
    }
    printf("%lld", (total - 1 + mod) % mod);
    return 0;
}
```

## Problem Statement

You are given a string. You can remove any number of characters from it, but you cannot change the order of the remaining characters. Find the total number of distinct non-empty subsequences that can be formed from the given string modulo $10^9 + 7$.

**Associated Portal Formulation (Musical Concert):**  
The Institution is organizing a musical concert in an auditorium. Audience booked their tickets online by selecting their suitable seats. Even though some seats were left unselected, the queue evaluates distinct seating arrangements and subset configurations.

### Input Format
- A single line containing the input string $S$.

### Output Format
- Print a single integer representing the count of distinct non-empty subsequences modulo $10^9 + 7$.
