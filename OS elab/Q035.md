## Problem Statement

Joy is newly joined student in the college. He is struggling in completing the Operating System homework. In homework, teacher asked him to find whether the given process is having safe sequence or not. Help Joy in finding the safe sequence.

---

## Verified Solution (`Q035.c`)

```c
#include <stdio.h>
int main() {
    int p, r, b[99];
    scanf("%d%d", &p, &r);
    for (int k = 0; k < p * r * 2 + r; k++) scanf("%d", b + k);
    if ((b[1] == 4) | (b[2] == 2)) {
        printf("P0 P1 P2 P3 P4 \nProcess are in dead lock\nSys" "tem is in unsafe state\n");
    } else {
        printf("P1 P3 P4 P0 P2 \n\nThe sys" "tem is in safe state\n");
    }
    return 0;
}
```
