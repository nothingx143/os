## Problem Statement

Bogar a student of Tamil Siddhar College on his birthday took his $n$ friends ($F_1, F_2, F_3 \dots F_n$) to SRM Restaurant for a treat. The waiter noted the order of $F_1, F_2, F_3 \dots F_n$ as $O_1, O_2, O_3 \dots O_n$ respectively. Assuming the waiter services the groups that come first to his table (FCFS), print the waiting time, time at which chef starts to prepare the order (Preparation start time / service time), and time in which the order completes (turnaround time) for each one of them. Print the average waiting and average turnaround time.

Assume $F_1$ gets the menu first and orders first, then $F_2$ and so on. Therefore the time at which the order is given to the waiter (Arrival time) changes for each friend.

### Input Format
The first line contains the Number of friends. The next lines contain the Friend name, order given time (Burst Time), and arrival time.

### Output Format
The first $n$ lines should print input values, waiting time, and turnaround time for each friend in each line. Print average waiting and average turnaround time in next two lines respectively.

## Verified C Solution

```c
#include <stdio.h>

int n, i, bt[30], at[30], wt[30], tat[30];
char f[30][50];
double sw, st;

#define CALC for(i=0;i<n;i++) scanf("%s", f[i]); \
    for(i=0;i<n;i++) scanf("%d", &bt[i]); \
    for(i=0;i<n;i++) scanf("%d", &at[i]); \
    wt[0]=0; tat[0]=bt[0]; sw=0; st=tat[0]; \
    for(i=1;i<n;i++) { wt[i]=wt[i-1]+bt[i-1]; tat[i]=wt[i]+bt[i]; sw+=wt[i]; st+=tat[i]; }

#define PRINT puts("\nWaiting Time"); \
    for(i=0;i<n;i++) printf("Time Taken for %s=%d\n", f[i], wt[i]); \
    printf("Average Waiting Time=%f\nTurnAround Time\n", n ? sw/n : 0); \
    for(i=0;i<n;i++) printf("Time Taken for %s=%d\n", f[i], tat[i]); \
    printf("Average TurnAround Time=%f\n", n ? st/n : 0);

int main() {
    if (scanf("%d", &n) != 1) return 0;
    CALC
    PRINT
    return 0;
}
```
