# Q073: Movie Festival Queries (Binary Lifting)

## Verified Solution (`Q073.c`)

```c
#include <stdio.h>

#define MAX 1000002
#define LVL 20

int up[LVL][MAX], n, q, a, b, i, j;

void init() {
    for (i = 0; i < MAX; i++)
        up[0][i] = MAX;
    for (i = 0; i < n; i++) {
        scanf("%d%d", &a, &b);
        if (b < up[0][a]) up[0][a] = b;
    }
}

void prep() {
    for (i = MAX - 2; i >= 1; i--)
        if (up[0][i + 1] < up[0][i])
            up[0][i] = up[0][i + 1];
}

void lift() {
    for (j = 1; j < LVL; j++)
        for (i = 1; i < MAX; i++) {
            int nxt = up[j - 1][i];
            up[j][i] = (nxt < MAX) ? up[j - 1][nxt] : MAX;
        }
}

int main() {
    if (scanf("%d%d", &n, &q) != 2) return 0;
    init();
    prep();
    lift();
    while(q--) {
        scanf("%d%d", &a, &b);
        int ans = 0;
        for (j = LVL - 1; j >= 0; j--)
            if (up[j][a] <= b) {
                ans += (1 << j);
                a = up[j][a];
            }
        printf("%d\n", ans);
    }
    return 0;
}
```

## Problem Description
In a movie festival, $n$ movies will be shown. You know the starting and ending time of each movie.
Process $q$ queries of the form: if you arrive at time $a$ and leave at time $b$, what is the maximum number of non-overlapping movies you can watch?
You can watch two movies if the first movie ends before or exactly when the second movie starts ($b_1 \le a_2$).

## Constraints
- $1 \le n, q \le 2 \cdot 10^5$
- $1 \le a < b \le 10^6$

## Input Format
- First line: Two integers $n$ and $q$ (number of movies and queries).
- Next $n$ lines: Two integers $a$ and $b$ (movie starting and ending times).
- Next $q$ lines: Two integers $a$ and $b$ (arrival and departure times for each query).

## Output Format
- For each query, print the maximum number of movies that can be watched.

## Solution Approach
- Precompute the earliest ending time of any movie starting at or after each time coordinate $x \in [1, 10^6]$ using suffix minimums:
  $$\text{up}[0][x] = \min(\text{up}[0][x], \text{up}[0][x+1])$$
- Build a binary lifting table across 20 levels:
  $$\text{up}[j][x] = \text{up}[j-1][\text{up}[j-1][x]]$$
- For each query $(a, b)$, jump greedily along powers of two from $j = 19$ down to $0$:
  if $\text{up}[j][a] \le b$, advance $a = \text{up}[j][a]$ and accumulate $2^j$ to the answer.
- Modularized into `init()`, `prep()`, `lift()`, and `main()` to satisfy strict cyclomatic complexity ($\text{CCN} \le 6$) and NLOC limits.

## Mandatory Keywords
- `while(q--)`
