# Challenge 43: Dead Lock Detection - Tree Climbers (Kayal and Moni)

## Verified Solution (`Q043.c`)

```c
#include <stdio.h>

int n, m, N, done, a[1000], f[50];

void P(int *p) {
    for (int j = 0; j < m; j++) printf("%d ", *p++);
}

void R(int p) {
    printf("P%d ", p + 1);
    P(a + N + p * m);
    P(a + p * m);
    if (!p) P(a + 2 * N);
    puts("");
}

int C(int p) {
    if (f[p]) return 0;
    int d = 0;
    for (int j = 0; j < m; j++)
        d += a[p * m + j] - a[N + p * m + j] > a[2 * N + j];
    return !d;
}

void U(int p) {
    f[p] = 1;
    done++;
    for (int j = 0; j < m; j++) a[2 * N + j] += a[N + p * m + j];
}

int step() {
    for (int p = 0; p < n; p++)
        if (C(p)) {
            U(p);
            return 1;
        }
    return 0;
}

void dead() {
    printf("System is in Deadlock");
    for (int i = 0; i < n; i++)
        if (!f[i]) printf(" P%d", i);
    puts("");
}

void rep() {
    while (step());
    if (done < n) dead();
    else puts("System is deadlock free");
}

int main() {
    scanf("%d%d", &n, &m);
    N = n * m;
    for (int i = 0; i < 2 * N + m; i++) scanf("%d", a + i);
    puts("\nProcess Allocation Max Available");
    for (int i = 0; i < n; i++) R(i);
    rep();
    return 0;
}
```

## Problem Description
Consider Kayal and Moni are tree climbers. They are provided with Palm and coconut tree for climbing. Maximum number of tree climbing will be allocated for them. They have to climb the trees based on the availability. They will be climbing as their wish. Based on their climbing and availability need will be calculated. Finally if able to satisfy then no problem, if not they have to wait for a long time. Here the number of persons and trees may change.

### Input Format
(In the following order)
1. Number of processes ($N$)
2. Number of Resources ($M$)
3. Maximum matrix ($N \times M$)
4. Allocation matrix ($N \times M$)
5. Available Resource vector ($M$)

### Output Format
- Table header: `\nProcess Allocation Max Available`
- For each process: `P<id> <Allocation values> <Max values> [<Available values if P1>]`
- Status message:
  - If deadlock free: `System is deadlock free`
  - If deadlocked: `System is in Deadlock P0 P1 ...`
