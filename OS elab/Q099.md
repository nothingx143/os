# Level 1 Challenge 99: Dining Philosophers Synchronization

## Problem Description
The Dining Philosophers problem illustrates process synchronization issues and deadlock prevention in concurrent algorithm design:
- 5 friends (A, B, C, D, E) sit at a round table for dinner.
- To complete dinner, each must acquire 2 forks (left fork and right fork).
- There are only 5 forks available on the table.
- Deadlock occurs if all try to acquire their left fork simultaneously.
- Deadlock avoidance: The last philosopher changes acquisition order (attempts right fork first, then left), preventing circular wait and allowing progress until all finish dinner.

The portal evaluates a deterministic 4-philosopher step trace showing fork acquisition, waiting states, releases, and cumulative completed counts.

## Input Format
Single integer indicating simulation run mode (e.g. `1` or `2`).

## Output Format
Full simulation state traces showing:
- Initial fork acquisitions and waiting statuses
- Progression of philosophers completing dinner and releasing forks
- Cumulative count of philosophers who completed dinner at each phase
