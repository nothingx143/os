# Challenge 46: Stack - Postfix to Infix Conversion

## Verified Solution (`Q046.cpp`)

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <cctype>

using namespace std;

bool isOperand(char x) {
    return isalnum(x);
}

string getInfix(string exp) {
    stack<string> s;
    int len = exp.length();
    for (int i = 0; i < len; i++) {
        if (isOperand(exp[i])) {
            string op(1, exp[i]);
            s.push(op);
        } else {
            string op1 = s.top(); s.pop();
            string op2 = s.top(); s.pop();
            s.push("(" + op2 + exp[i] + op1 + ")");
        }
    }
    return s.top();
}

int main() {
    string exp;
    if (cin >> exp) {
        cout << getInfix(exp) << endl;
    }
    return 0;
}
```

## Problem Description
Hassan gets a job in a software company in Hyderabad. His teammate Jocelyn gives him a task to implement Postfix to Infix Conversion for a given postfix expression using a stack.

### Algorithm
1. Read the postfix expression character by character.
2. If the symbol is an operand (letter/digit), push it as a string onto the stack.
3. If the symbol is an operator:
   - Pop the top 2 values from the stack (`op1`, `op2`).
   - Construct the infix string: `"(" + op2 + operator + op1 + ")"`.
   - Push the resulting string back onto the stack.
4. When expression processing is complete, the single remaining string on the stack is the desired fully parenthesized infix expression.

### Input Format
Single line representing the postfix expression.

### Output Format
Single line representing the fully parenthesized infix expression.
