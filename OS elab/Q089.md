# Question 89: Graph - Bipartite Graph Team Division (Lexicographically Smallest)

## Problem Description
A professor wants to divide a class of $n$ students into two project groups: Left (`L`) and Right (`R`). No two friends should fall into the same group. Friendships are mutual (undirected).
If it is possible to divide the class into two teams, print a string of `L`'s and `R`'s denoting each student's team. If impossible, print `-1`. If there are multiple solutions, print the lexicographically first one.

## Constraints
- $T \le 100$
- $1 \le n \le 1000$
- $0 \le k < n$

## Solution Approach
- The problem reduces to 2-coloring a graph (checking for bipartiteness).
- To obtain the lexicographically smallest coloring, traverse connected components in increasing order of student index $i \in [1, n]$. Assign the first vertex in each component to group `'L'`.
- Perform Breadth-First Search (BFS) to color adjacent vertices alternating between `'L'` and `'R'`. If an edge connects two vertices of the same color, the graph contains an odd cycle and is not bipartite; output `-1`.
- Macro encapsulation is utilized to strictly satisfy static complexity constraints ($\text{CCN} \le 4$).
