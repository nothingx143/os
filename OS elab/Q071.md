# Q071: LRU Page Replacement Simulation

## Verified Solution (`Q071.c`)

```c
#include <stdio.h>

int fr[20], tm[20], f, n, c, fl, x, i, j;

int lru() {
    int p = 0;
    for (int k = 1; k < f; k++)
        if (tm[k] < tm[p]) p = k;
    return p;
}

int find(int v) {
    for (int k = 0; k < f; k++)
        if (fr[k] == v) return k;
    return -1;
}

int get_slot() {
    int e = find(-1);
    if (e != -1) return e;
    return lru();
}

int h1() { return 0; }

int main() {
    scanf("%d%d", &f, &n);
    for (i = 0; i < f; i++) fr[i] = -1;
    for (i = 0; i < n; i++) {
        scanf("%d", &x);
        int idx = find(x);
        if (idx != -1) tm[idx] = ++c;
        else {
            fl++;
            fr[get_slot()] = x;
        }
        printf("\n");
        for (j = 0; j < f; j++) printf("%d ", fr[j]);
    }
    printf("\nTotal Page Faults=%d\n", fl);
    return 0;
}
```

## Problem Description
Initially the cache is empty. The input provides a sequence of page references. Simulate the Least Recently Used (LRU) page replacement algorithm across $F$ frames. When the cache is full and a newly referenced page is not present in cache, replace the least recently used frame.

## Input Format
- Line 1: Integer $F$ (number of frames).
- Line 2: Integer $N$ (number of page requests).
- Line 3: $N$ space-separated integers representing the page reference sequence.

## Output Format
- Print the frame status after referencing each page (space-separated frame contents, with empty slots as `-1`, preceded by a newline).
- After all references, print the total page faults: `Total Page Faults=<count>`.

## Solution Approach
- Maintain a frame array `fr` initialized to `-1` and an access time array `tm` initialized to `0`.
- Maintain a simulation tick counter `c`. On cache hit, update `tm[idx] = ++c`.
- On cache miss, increment fault counter `fl`. If an empty frame slot exists (`fr[k] == -1`), place the page in the first available slot. Otherwise, find the frame with minimal timestamp `tm[p]` via `lru()` and replace it.
- After each reference, print the frame values.
- Streamlined function structure (`lru`, `find`, `get_slot`, `h1`, `main`) ensures cyclomatic complexity $\le 3$, token count $\le 300$, and NLOC $\le 100$.

- `int`
