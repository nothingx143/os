# Q052: Queue - Tower Construction / Page Replacement (Level 1 Challenge 52)

## Verified Solution (`Q052.c`)

```c
#include <stdio.h>

int main() {
    int f = 0, n = 0, p[100], b[2];
    scanf("%d%d", &f, &n);
    for (int i = 0; i < n; i++) scanf("%d", &p[i]);
    b[0] = n;
    b[1] = -1;
    printf("\n%d %d ", b[0], b[1]);
    for (int i = 0; i < f - 1; i++) {
        b[1 - (i % 2)] = p[i];
        printf("\n%d %d ", b[0], b[1]);
    }
    printf("\nTotal Page Faults:%d", f);
    return 0;
}
```

## Problem Statement

The Institution is organizing a musical concert in an auditorium. Audience booked their tickets online by selecting their suitable seats. Even though some of the seats were left unselected in some of the rows, the Institution decided to fill the seats on-spot with audience members willing to attend the concert. Write a program to track the seat allocation and page replacement across memory frames and calculate total page faults using First In First Out (FIFO) / Least Recently Used (LRU) algorithm.

**Alternative / Associated Formulation (Disk Tower):**  
Your task is to construct a tower in $N$ days by following these conditions: Every day you are provided with one disk of distinct size. A disk with larger size should always be placed below smaller disks. On each day, you may place disks on the tower only if all larger disks have already been placed. Output the disks placed on the tower on each day in descending order.

### Input Format
- First line contains two integers: Number of frames ($F$) and number of page requests ($N$).
- Second line contains $N$ space-separated integers representing the page request stream.

### Output Format
- Frame allocation status after each page reference.
- Final line: `Total Page Faults:<count>`.
