# Challenge 61: File Organization - Single Level Directory File Search

## Problem Description
Bogar was teaching File Organization techniques to his fellow Siddhars. Agathiyar wants to create a single-level directory and $N$ files under it. Once the files are created, Siddhar Pulipani provides a file name to check whether the file exists in the directory or not.

### Requirements & Constraints
- Structure name: `Files` with structure variable `dir`.
- Data members:
  ```c
  struct Files {
      char dname[10], fname[10][10];
      int fcnt;
  };
  ```
- File lookup: access `dir.fname[i]`.

### Input Format
- Line 1: Directory name (`dir.dname`).
- Line 2: Number of files $N$ (`dir.fcnt`).
- Next $N$ lines: File names.
- Final line: Target file name to search.

### Output Format
- If file is found: `File <name> is found`.
- If file is not found: `File <name> not found`.

## Solution (C)
```c
#include <stdio.h>
#include <string.h>

struct Files {
    char dname[10],fname[10][10];
    int fcnt;
} dir;

int check_file(char *target) {
    for (int i = 0; i < dir.fcnt; i++) {
        if (strcmp(dir.fname[i], target) == 0) return 1;
    }
    return 0;
}

void print_result(char *target, int found) {
    if (found) printf("File %s is found\n", target);
    else printf("File %s not found\n", target);
}

int main() {
    char target[20];
    scanf("%s", dir.dname);
    scanf("%d", &dir.fcnt);
    for (int i = 0; i < dir.fcnt; i++) {
        scanf("%s", dir.fname[i]);
    }
    scanf("%s", target);
    print_result(target, check_file(target));
    return 0;
}
```
