# Q001: CPU Scheduling (Level 1 Challenge 1)

## Verified Solution (`Q001.c`)

```c
#include <stdio.h>
#include <string.h>

#define F(i,n) for(i=0;i<n;i++)
#define S(i) { int p=i; for(j=i+1;j<n;j++) if(b[j]<b[p]) p=j; int t=b[i];b[i]=b[p];b[p]=t; t=a[i];a[i]=a[p];a[p]=t; char s[100]; strcpy(s,f[i]); strcpy(f[i],f[p]); strcpy(f[p],s); }

char f[100][100];
int b[100], a[100], w[100], t[100], n, i, j, s1, s2;

int main() {
    if (scanf("%d", &n) != 1) return 0;
    F(i,n) scanf("%s", f[i]);
    F(i,n) scanf("%d", b+i);
    F(i,n) scanf("%d", a+i);
    F(i,n) S(i);
    for (i=1; i<n; i++) { w[i] = w[i-1] + b[i-1]; s1 += w[i]; }
    puts("Sorting Depend on Burst Time");
    F(i,n) { t[i] = b[i] + w[i]; s2 += t[i]; printf("%s %d %d\n", f[i], b[i], a[i]); }
    puts("Waiting Time");
    F(i,n) printf("Time Taken for %s=%d\n", f[i], w[i]);
    printf("Average Waiting Time=%lf\nTurnAround Time\n", (double)s1 / n);
    F(i,n) printf("Time Taken for %s=%d\n", f[i], t[i]);
    printf("Average TurnAround Time=%lf\n", (double)s2 / n);
    return 0;
}
```

## Problem Statement

Bogar a student of TAMIL Siddha College On his birthday took his n Friends (F1, F2, F3. Fn) to Naturopathy hotel for a treat. The waiter noted the order of F1, F2, F3. Fn as O1, O2, O3. On respectively. Bogar asked the waiter about the type of algorithm he follows to give order to chef to prepare. Waiter told Bogar that he follows the SJF (Non preemptive shortest job first algorithm) as it minimizes the waiting time so more number of customers are happy from their service and so they come back.

Print the waiting time, time at which chef starts to prepare the order (Preparation start time) (service time) and time in which the order completes (turnaround time) for each one of them. Print the average waiting and average turnaround time. Assume F1 gets the menu first and orders first then F2 and so on Therefore the time at which the order is given to the waiter (Arrival time) changes for each friend.

### Input Format
* The first line contains the Number of friend/s ($n$).
* The next $n$ lines contain the Friend name.
* The next line contains $n$ order give times (Burst Time).
* The next line contains $n$ arrival times (Arrival Time = 0).

### Output Format
* The first $n$ lines should print: `FriendName BurstTime ArrivalTime`
* Next line: `Waiting Time`
* Next $n$ lines: `Time Taken for FriendName=WaitingTime`
* Next line: `Average Waiting Time=X.XXXXXX`
* Next line: `TurnAround Time`
* Next $n$ lines: `Time Taken for FriendName=TurnaroundTime`
* Next line: `Average TurnAround Time=Y.YYYYYY`
