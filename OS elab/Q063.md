# Level 1 - Challenge 63: Binary Search Tree Insertion and Traversal

## Problem Description
Darsh, Ratik, Swathy are good friends studying Pre-final year B.E. Swathy's uncle asks them to make an application for Insertion in a Binary Search Tree:
- The left subtree for any given node will only contain nodes which are lesser than the current node.
- The right subtree for any given node will only contain nodes which are greater than the current node.
- Each subtree must also follow the above rules of BST.

## Constraints
- $0 < n < 100$
- $0 < arr[i] < 1000$

## Input Format
- First line: size of the array $n$.
- Second line: array elements according to the array size.

## Output Format
- Single line representing the binary search tree (inorder traversal, space-separated).

## Solution Approach
- Implements dynamic BST node allocation with `newNode`.
- Recursively inserts elements maintaining the BST invariant.
- Traverses the tree in-order to output the sorted elements in linear time.
- Engineered with auxiliary functions to satisfy the strict cyclomatic complexity threshold ($\text{CCN} \le 1$).

## Mandatory Keywords
- `struct node* newNode(int item) `
- `struct node *left,*right;`

## Complexity Metrics
- **Cyclomatic Complexity (CCN):** 1 (Threshold $\le 1$)
- **Token Count:** 275 (Threshold $\le 290$)
- **NLOC:** 41 (Threshold $\le 50$)
