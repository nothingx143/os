## Verified Solution (`Q042.c`)

```c
#include <stdio.h>

long long a[3005];
int n, i, j, k;

int find_g(int j) {
    for (k = j + 1; k < n; k++)
        if (a[k] < a[j]) return k;
    return -1;
}

void solve() {
    for(i=0;i<n;i++) {
        long long ans = -1;
        for (j = i + 1; j < n; j++) {
            if(a[j]>a[i]) {
                int g = find_g(j);
                if (g >= 0) ans = a[g];
                break;
            }
        }
        printf("%lld ", ans);
    }
}

int main() {
    if (scanf("%d", &n) < 1) return 0;
    for(i=0;i<n;i++) scanf("%lld", a + i);
    solve();
    return 0;
}
```

## Problem Statement

You are given an array A of N integers. Now, two functions F(X) and G(X) are defined:
- F(X): The smallest index Z such that Z > X and A[Z] > A[X] (Next Greater Element to the right).
- G(X): The smallest index Z such that Z > X and A[Z] < A[X] (Next Smaller Element to the right).

For each index i (from 0 to N-1), determine the value of A[G(F(i))]. If F(i) or G(F(i)) does not exist, consider the answer as -1.
