# Q051: Queue - Linked List Implementation and Dequeue Operation

## Verified Solution (`Q051.c`)

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

struct node *front = NULL;
struct node *rear = NULL;

void enqueue(int d) {
    struct node* new_n;
    new_n = (struct node*)malloc(sizeof(struct node));
    new_n->data = d;
    new_n->next = NULL;
    if (front == NULL) {
        front = rear = new_n;
    } else {
        rear->next = new_n;
        rear = new_n;
    }
}

void dequeue() {
    if (front == NULL) return;
    struct node *temp = front;
    front = front->next;
    if (front == NULL) rear = NULL;
    free(temp);
}

void display() {
    struct node *temp = front;
    while (temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }
    printf("\n");
}

int main() {
    int n, x;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &x);
        enqueue(x);
    }
    display();
    dequeue();
    display();
    return 0;
}
```

## Problem Description
Joe Root is a Placement trainer working as a CDC trainer in a reputed institution. During training, students were struggling with the queue concept. Joe Root provides final year students a task to implement a Queue using a singly linked list and perform deletion (dequeue) from the queue following FIFO (First-In, First-Out) ordering.

### Input Format
- First line indicates the size of the queue $N$.
- Second line indicates the $N$ space-separated integer elements of the queue.

### Output Format
- First line indicates the inserted elements in the queue using linked list traversal.
- Second line indicates the remaining elements after one element is dequeued from the queue.
