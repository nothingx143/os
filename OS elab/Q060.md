# Q060: Queue - Priority Queue Monk and Multiplication (Level 1 Challenge 60)

## Verified Solution (`Q060.c`)

```c
#include <stdio.h>

int main() {
    int n;
    if (scanf("%d", &n) < 1) return 0;
    long long a[n];
    long long biggest = -1, big = -1, small = -1;
    for (int i = 0; i < n; i++) {
        scanf("%lld", a + i);
        if(a[i]>biggest) {
            small = big;
            big = biggest;
            biggest = a[i];
        } else if (a[i] > big) {
            small = big;
            big = a[i];
        } else if (a[i] > small) {
            small = a[i];
        }
        if(biggest<big) biggest = big;
        if (i < 2) printf("-1\n");
        else printf("%lld\n", biggest * big * small);
    }
    return 0;
}
```

## Problem Statement

The Monk recently learnt about priority queues and decided to practice with an array of $N$ integers. For each element processed from index 1 to $N$, he wants to find the product of the 3 largest numbers among the numbers seen so far. If less than 3 numbers have been processed, print -1.

**Associated Portal Formulation (Professor Chirag Page Algorithm):**  
Professor CHIRAG told his students about page algorithm that: A page Replacement Algorithm is used to Replace the page on the Main memory with the one present in the Secondary Memory. Find the priority queue replacement sequence.

### Input Format
- First line: Integer $N$ (number of elements).
- Second line: $N$ space-separated integers representing the array elements.

### Output Format
- Print $N$ lines. The $i$-th line should display the product of the 3 largest numbers seen among the first $i$ elements, or -1 if $i < 3$.
