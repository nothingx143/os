# Level 1 - Challenge 67: Single Level Directory File Creation and Listing

## Problem Description
Bogar a student of Murugan was teaching File Organization techniques to his fellow Siddhars. Agathiyar one of the Siddhars raised a question in creating a directory and files. Now Agathiyar wants to create a directory and $n$ files under the directory. Once the files are created, Agathiyar needs to list all the files created to his fellow Siddhars.

## Constraints
- File and directory names are alphanumeric strings.
- Directory contains $n$ files.

## Input Format
- First line: Directory name (`dname`).
- Second line: Number of files (`fcnt`).
- Following lines: Names of the files under the directory.

## Output Format
- Header `\nThe Files are\n` followed by the list of created file names, one per line.

## Solution Approach
- Uses structure `Files` with member array `fname[50][50]` and instance `dir` to store files within the single-level directory.
- Populates `dir.fname[i]` iteratively and prints each file under the directory with the required leading newline formatting.

## Mandatory Keywords
- `main`
- `int`
- Data structure: `struct Files { char dname[50],fname[50][50]; int fcnt; } dir;`
- Access expression: `dir.fname[i]`
