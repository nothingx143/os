# Q069: Forest Queries (2D Prefix Sums)

## Verified Solution (`Q069.c`)

```c
#include <stdio.h>

int p[1005][1005];
char s[1005];

int main() {
    int n, q, i, j, y1, x1, y2, x2;
    if (scanf("%d %d", &n, &q) != 2) return 0;
    for(i=1;i<=n;i++) {
        scanf("%s", s + 1);
        for (j = 1; j <= n; j++) {
            p[i][j] = (s[j] == '*') + p[i - 1][j] + p[i][j - 1] - p[i - 1][j - 1];
        }
    }
    while (q--) {
        scanf("%d %d %d %d", &y1, &x1, &y2, &x2);
        if (y1 > y2 || x1 > x2) printf("0\n");
        else printf("%d\n", p[y2][x2] - p[y1 - 1][x2] - p[y2][x1 - 1] + p[y1 - 1][x1 - 1]);
    }
    return 0;
}
```

## Problem Description
You are given an $n \times n$ grid representing the map of a forest. Each square is either empty (`.`) or contains a tree (`*`). The upper-left square has coordinates $(1, 1)$, and the lower-right square has coordinates $(n, n)$.
Your task is to process $q$ queries of the form: how many trees are inside a given rectangle from $(y_1, x_1)$ to $(y_2, x_2)$?

## Constraints
- $1 \le n \le 1000$
- $1 \le q \le 2 \cdot 10^5$
- Coordinates $1 \le y_1, y_2, x_1, x_2 \le n$

## Input Format
- First line: Two integers $n$ and $q$ (size of the forest and number of queries).
- Next $n$ lines: Strings of length $n$ consisting of `.` and `*`.
- Following $q$ lines: Four integers $y_1, x_1, y_2, x_2$ describing each rectangle query.

## Output Format
- Print the number of trees inside each rectangle query on a new line.

## Solution Approach
- Precomputes 2D prefix sums where $p[i][j]$ stores the total number of trees in the subgrid $[1 \dots i] \times [1 \dots j]$ in $O(n^2)$ time:
  $$p[i][j] = (s[j] == '*') + p[i - 1][j] + p[i][j - 1] - p[i - 1][j - 1]$$
- Answers each rectangular region query in $O(1)$ time:
  $$\text{trees} = p[y_2][x_2] - p[y_1 - 1][x_2] - p[y_2][x_1 - 1] + p[y_1 - 1][x_1 - 1]$$
- Handles inverted coordinate queries ($y_1 > y_2$ or $x_1 > x_2$) safely by outputting 0.

## Mandatory Keywords
- `for(i=1;i<=n;i++)`
