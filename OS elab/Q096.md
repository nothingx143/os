# Q096: Hashing (Level 1 Challenge 96)

## Verified Solution (`Q096.c`)

```c
#include <stdio.h>
#include <stdlib.h>

int cmp(const void *a, const void *b) {
    return (*(int*)a - *(int*)b);
}

int a[100005];

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while(T--) {
        int n;
        if (scanf("%d", &n) != 1) break;
        for (int i = 0; i < n; i++) {
            scanf("%d", &a[i]);
        }
        qsort(a, n, sizeof(int), cmp);
        int ans = 0;
        int survived = 1;
        for (int i = 0; i < n; i++) {
            int advance = i + (i / 6);
            if (a[i] - advance <= 0) {
                survived = 0;
                ans = i;
                break;
            }
        }
        if (survived) {
            printf("Rick now go and save Carl and Judas\n");
        } else {
            printf("Goodbye Rick\n%d\n", ans);
        }
    }
    return 0;
}
```

## Problem Description
Rick was besieged by walkers after the Governor's raid on the prison. They are approaching him from all sides. Assume Rick possesses a limitless supply of ammo, but his gun can only hold 6 bullets at a time.

- It takes 1 second for Rick to shoot and kill a single walker.
- Every time 1 second passes (either shooting a walker or reloading), all surviving walkers advance 1 metre closer to Rick.
- When the 6-round chamber is empty, Rick must reload, which takes 1 second (and all walkers advance 1 metre during reload).
- Rick shoots the closest walker first.
- If any walker reaches Rick's position (distance $\le 0$ after advancement), Rick dies immediately.

Determine whether Rick can survive all walkers across $T$ test cases.

### Input Format
- First line: An integer $T$ denoting the number of test cases.
- For each test case:
  - First line: An integer $N$ denoting the number of walkers.
  - Second line: $N$ space-separated integers denoting the initial distance of each walker from Rick.

### Output Format
- If Rick survives all $N$ walkers: print `Rick now go and save Carl and Judas`.
- If Rick dies: print `Goodbye Rick` on the first line, followed by the total number of walkers he managed to kill before dying on the second line.

## Constraints
- $1 \le T \le 10$
- $1 \le N \le 10^5$
- $1 \le \text{distance} \le 10^9$

## Solution Approach
- Sort all walkers by their initial distance in non-decreasing order using `qsort`.
- For the $i$-th walker (0-indexed), the total elapsed time before Rick can shoot it is:
  $$\text{advance} = i + \lfloor i / 6 \rfloor$$
  where $i$ is the time spent shooting previous walkers and $\lfloor i / 6 \rfloor$ is the total reload seconds elapsed.
- If at any point $a[i] - \text{advance} \le 0$, the walker reaches Rick and Rick dies. Rick has eliminated $i$ walkers before death.
- If all $N$ walkers are shot without any walker reaching distance $\le 0$, Rick survives.
