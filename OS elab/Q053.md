# Q053: Page Replacement - FIFO Faults (Level 1 Challenge 53)

## Verified Solution (`Q053.c`)

```c
#include <stdio.h>

int f, n, a[999], b[999], pf;

int in_frame(int x) {
    for (int j = 0; j < f; j++)
        if (x == b[j]) return 1;
    return 0;
}

void solve() {
    for (int i = 0; i < n; i++) {
        if (!in_frame(a[i])) {
            b[pf % f] = a[i];
            pf++;
        }
    }
}

int main() {
    if (scanf("%d%d", &f, &n) < 2) return 0;
    for (int i = 0; i < f; i++) b[i] = -1;
    for (int i = 0; i < n; i++) scanf("%d", a + i);
    solve();
    printf("Faults=%d", pf);
    return 0;
}
```

## Problem Statement

Professor CHIRAG told his students about page algorithm that: A Page Replacement Algorithm is used to replace the page in the Main memory with the one present in the Secondary Memory. In FIFO (First In First Out) Algorithm, the page that entered first has to leave first when all the frames in the memory are filled and the entering page does not create a hit. A hit is a situation in which the same page you are entering is already present in main memory. When a page is replaced it creates a FAULT; otherwise, if it is already present in main memory, it is referred to as a HIT. After this, Professor CHIRAG asked his students to solve this problem to find the total number of page Faults.

**Alternative Formulation (Stolen Number Hints):**  
A positive integer $X$ has been stolen. But luckily, $N$ hints are available, each described by two integers $a_i$ and $d_i$, meaning that $|X - a_i| = d_i$.

### Input Format
- First line contains two integers: the number of frames ($f$) and the number of pages ($n$).
- Second line contains the $n$ page reference values.

### Output Format
- Print `Faults=<count>` representing the total number of page faults.
