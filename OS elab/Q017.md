# Q017: File Allocation (Level 1 Challenge 17)

## Verified Solution (`Q017.c`)

```c
#include <stdio.h>

int t, n, i, ans, max_prod, max_r, l[105], r[105];

#define READ for(i=0;i<n;i++) scanf("%d",&l[i]); for(i=0;i<n;i++) scanf("%d",&r[i]);

#define SOLVE max_prod = -1; max_r = -1; ans = 0; \
    for(i=0;i<n;i++) { \
        int p = l[i] * r[i]; \
        if(p > max_prod || (p == max_prod && r[i] > max_r)) { \
            max_prod = p; max_r = r[i]; ans = i + 1; \
        } \
    } \
    printf("%d\n", ans);

int main() {
    if (scanf("%d", &t) != 1) return 0;
    while(t--) {
        scanf("%d", &n);
        READ
        SOLVE
    }
    return 0;
}
```

## Problem Statement

Raina a huge movie fan. He likes watching different kinds of movies: from drama movies to comedy movies, from teen movies to horror movies. He is planning to visit cinema this weekend, but he's not sure which movie he should watch. There are $n$ movies to watch during this weekend. Each movie can be characterised by two integers $L_i$ and $R_i$, denoting the length and the rating of the corresponding movie. Raina wants to watch exactly one movie with the maximal value of $L_i \times R_i$. If there are several such movies, he would pick a one with the maximal $R_i$ among them. If there is still a tie, he would pick the one with the minimal index among them. Your task is to help Raina to pick a movie to watch during this weekend.

### Input Format
- Line 1: Number of test cases $t$
- For each test case:
  - Line 1: Number of movies $n$
  - Line 2: $n$ space-separated integers representing lengths $L_i$
  - Line 3: $n$ space-separated integers representing ratings $R_i$

### Output Format
For each test case, print the 1-based index of the chosen movie on a separate line.
