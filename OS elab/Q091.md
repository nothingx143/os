# Q091: Hashing (Level 1 Challenge 91)

## Verified Solution (`Q091.c`)

```c
#include <stdio.h>

char key[256], ans[256];
int n, ch, i;
char a, b, tmp;

int toInt(char a) {
    return (int)(unsigned char)a;
}

#define INIT_KEYS for (i = 0; i < 256; i++) key[i] = i;
#define READ_SWAPS for (i = 0; i < n; i++) { scanf(" %c %c", &a, &b); tmp = key[toInt(a)]; key[toInt(a)] = key[toInt(b)]; key[toInt(b)] = tmp; }
#define INVERT_KEYS for (i = 0; i < 256; i++) ans[toInt(key[i])] = i;
#define CONSUME_NL while ((ch = getchar()) != '\n' && ch != EOF);
#define PROCESS_TEXT while ((ch = getchar()) != EOF) putchar(ans[toInt(ch)]);
#define SOLVE INIT_KEYS; READ_SWAPS; INVERT_KEYS; CONSUME_NL; PROCESS_TEXT;

void solve() {
    SOLVE;
}

int main() {
    scanf("%d", &n);
    solve();
    return 0;
}
```

## Problem Statement

Anandi and Boby have known each other since they were children. However, as they grew older, Boby began to act strangely, which annoyed Anandi. Anandi was taking a break after coding a big programme when Boby appeared out of nowhere and switched some alphabet keys on her keyboard.

When Anandi saw this, he became enraged and determined to terminate their friendship once and for all. Boby, as we all know, has a wonderful heart and never does anything wrong on purpose. He opted to use the same keyboard configuration for the rest of the programme. Given the original code fragment that Boby must write, you must give Boby the code that he must type in order to obtain the original code as output.

Help him saving his friendship with Anandi.

CONSTRAINTS:

1 <= N <= 106

1 <= |length of codefragment| <= 106

code fragment contains uppercase and lowercase english alphabets only and space.

A,B belongs to Alphabet set (both upper case and lower case letters are included).

INPUT :

First line of the input contains a single integer N denoting the number of swaps done by Boby. Next N lines contain a pair of characters A,B denoting the characters which are swapped by Boby (Note that Boby performs these swaps in the given order). From the very next line of input the remaining fragment of the code starts and ends with an end of file character.

OUTPUT:

print the fragment of the program that Boby types.
