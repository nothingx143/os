# Challenge 49: Stack - Prefix to Postfix Conversion

## Verified Solution (`Q049.cpp`)

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isOperator(char x) {
    return (x == '+' || x == '-' || x == '/' || x == '*' || x == '^');
}

string preToPost(string pre_exp) {
    stack<string> s;
    int len = pre_exp.length();
    for (int i = len - 1; i >= 0; i--) {
        if (isOperator(pre_exp[i])) {
            string op1 = s.top(); s.pop();
            string op2 = s.top(); s.pop();
            s.push(op1 + op2 + pre_exp[i]);
        } else {
            s.push(string(1, pre_exp[i]));
        }
    }
    return s.top();
}

int main() {
    string pre_exp;
    if (cin >> pre_exp) {
        cout << "Postfix:" << preToPost(pre_exp) << endl;
    }
    return 0;
}
```

## Problem Description
Hassan gets a job in a software company in Hyderabad. The training period for the first three months is 20,000 salary, then incremented to 25,000. During training, programming tasks are given daily. His teammate Jocelyn gives him a task to implement Prefix to Postfix Conversion for a given expression using a stack.

### Functional Description
1. Read the Prefix expression in reverse order (from right to left).
2. If the symbol is an operand, push it onto the stack.
3. If the symbol is an operator, pop two operands from the stack (`op1`, `op2`).
4. Create a string by concatenating the two operands and the operator after them: `string = op1 + op2 + operator`.
5. Push the resultant string back to the stack.
6. Repeat the above steps until the entire Prefix expression has been read.
7. Return the top of the stack as the final postfix expression.

### Input Format
Single line representing the prefixed expression.

### Output Format
Single line representing the postfix expression with the prefix `Postfix:`.
