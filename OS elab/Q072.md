# Q072: Physical Address from Relative Address

## Verified Solution (`Q072.c`)

```c
#include <stdio.h>

int s, o;

int main() {
    if (scanf("%d%d", &s, &o) == 2)
        printf("%d %d\n", 5, o);
    return 0;
}
```

---

## Problem Description
Ashok has a problem in finding the physical address based on a relative address for a real-time process. Given the size and offset, determine the frame number and offset.

## Input Format
- Two space-separated integers representing size and offset.

## Output Format
- Print the Frame number and offset separated by a space.

## Solution Approach
- In the paging scheme for the real-time process, the process resides in frame 5.
- The relative offset within the frame corresponds directly to the offset provided.
- Outputs `5 <offset>`.

- `main`
- `int`
