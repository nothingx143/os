# Challenge 47: Stack - Postfix to Prefix Conversion

## Verified Solution (`Q047.cpp`)

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <cctype>

using namespace std;

bool isOperand(char x) {
    return isalnum(x);
}

string postToPre(string post_exp) {
    stack<string> s;
    int len = post_exp.length();
    for (int i = 0; i < len; i++) {
        if (isOperand(post_exp[i])) {
            string op(1, post_exp[i]);
            s.push(op);
        } else {
            string op1 = s.top(); s.pop();
            string op2 = s.top(); s.pop();
            s.push(post_exp[i] + op2 + op1);
        }
    }
    return s.top();
}

int main() {
    string post_exp;
    if (cin >> post_exp) {
        cout << postToPre(post_exp) << endl;
    }
    return 0;
}
```

## Problem Description
Hassan gets a job in a software company in Hyderabad. His teammate Jocelyn gives him a task to implement Postfix to Prefix Conversion for a given postfix expression using a stack.

### Algorithm
1. Read the postfix expression character by character from left to right.
2. If the symbol is an operand (letter/digit), push it as a string onto the stack.
3. If the symbol is an operator:
   - Pop two operands from the stack (`op1`, `op2`), where `op1` is the right operand and `op2` is the left operand.
   - Form a new prefix string: `operator + op2 + op1`.
   - Push the resulting string back onto the stack.
4. When expression processing is complete, the single remaining string on the stack is the desired prefix expression.

### Input Format
Single line representing the postfix expression.

### Output Format
Single line representing the prefix expression.
