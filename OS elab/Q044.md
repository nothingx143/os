# Challenge 44: Stack - Fantabulous Pairs (Mancunian and Fantabulous Pairs)

## Verified Solution (`Q044.c`)

```c
#include <stdio.h>

typedef long long int llint;
#define M 1000005

int n, a[M], nxt[M], prv[M], T[M], top;
llint stack[M];

void push(llint num) { stack[top++]=num; }
llint pop() { return stack[--top]; }
llint peek() { return stack[top - 1]; }
int empty() { return !top; }
int sz() { return top; }

void run_st(int *target, int start, int end, int step) {
    top = 0;
    for (int i = start; i != end; i += step) {
        while (!empty() && a[i] > a[peek()]) target[pop()] = i;
        push(i);
    }
}

void upd(int d, int s) { if (s > T[d]) T[d] = s; }
void chk(int i) { if (nxt[i] < n) upd(nxt[i] - i - 1, i - prv[i]); }
void calc() { for (int i = 0; i < n; i++) chk(i); }

llint sum() {
    llint s = 0;
    for (int i = 0; i < n; i++) s += T[i];
    return s;
}

void init() {
    for (int i = 0; i < n; i++) { nxt[i] = n; prv[i] = -1; }
}

int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", a + i);
    init();
    run_st(nxt, 0, n, 1);
    run_st(prv, n - 1, -1, -1);
    calc();
    printf("%lld\n", sum());
    return 0;
}
```

## Problem Description
An array of length at least 2 having distinct integers is said to be **fantabulous** iff the second highest element lies strictly to the left of the highest value.

For example, `[1, 2, 13, 10, 15]` is fantabulous as the second-highest value `13` lies to the left of the highest value `15`.
For every fantabulous array, we define a fantabulous pair `(a, b)` where `a` denotes the index of the second-highest value (1-indexed) and `b` denotes the index of the highest value (1-indexed).

Given an array, find the total number of distinct fantabulous pairs overall its subarrays.

### Constraints
- $1 \le N \le 10^6$
- $1 \le \text{array elements} \le 10^9$
- Array elements are distinct.

### Input Format
- The first line contains an integer $N$ denoting the length of the array.
- The next line contains $N$ distinct integers denoting the elements of the array.

### Output Format
- Output a single integer which is the answer to the problem.

## Algorithm & Implementation
We employ two monotonic stacks to determine in $O(N)$ time:
1. `nxt[i]`: The index of the next greater element to the right of index `i`.
2. `prv[i]`: The index of the previous greater element to the left of index `i`.

For every element `i` having `nxt[i] < n`:
- The right-span difference is `diff = nxt[i] - i - 1`.
- The maximum valid left-span where `i` can act as the second highest element is `span = i - prv[i]`.
- We maintain the maximum span `T[diff] = max(T[diff], span)` for every possible difference.
- The final answer is the sum over all `T[diff]` for $0 \le \text{diff} < n$.
