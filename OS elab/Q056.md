# Q056: Queue - Array Implementation and Step-by-Step Enqueue Display

## Verified Solution (`Q056.c`)

```c
#include <stdio.h>

int queue[105];
int front = 0, rear = -1;

void display() {
    int i;
    for(i=front;i<=rear;i++)
        printf("%d%c", queue[i], i == rear ? '\n' : ' ');
}

void enqueue(int data) {
    int i;
    for(i=front;i<=rear;i++)
        printf("%d ", queue[i]);
    printf("Enqueuing %d\n", data);
    queue[++rear] = data;
}

int main() {
    int n, data, j;
    scanf("%d", &n);
    for (j = 0; j < n; j++) {
        scanf("%d", &data);
        enqueue(data);
    }
    display();
    return 0;
}
```

---

## Problem Description
Sathya is a DS expert training youngsters struggling in Data Structures. Sathya gives students a task to implement a Queue in FIFO (First-In, First-Out) order using an array and display the current queue contents followed by the enqueued element at each insertion step, followed by the final queue state.

### Input Format
- First line indicates the size of the queue $N$.
- Second line indicates the $N$ space-separated integer elements to be enqueued.

### Output Format
- Each line indicates the enqueued state of the queue: existing elements followed by `Enqueuing <data>`.
- The final line indicates the complete queue elements.
