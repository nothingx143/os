# Question 87: Graph - Road Construction (Disjoint Set Union)

## Problem Description
There are $n$ cities and initially no roads between them. Every day a new road is constructed, with a total of $m$ roads.
After each day, output:
1. The number of connected components.
2. The size of the largest connected component.

## Constraints
- $1 \le n \le 10^5$
- $1 \le m \le 2 \times 10^5$
- $1 \le a, b \le n$

## Solution Approach
- Use Disjoint Set Union (DSU) tracking the component sizes (`sz` array).
- Initially, there are $n$ components, each of size 1, and the maximum size is 1.
- For each edge, find the root representatives of both endpoints. If they belong to different components, union them, decrement the component count, add sizes, and update the maximum component size.
- Preprocessor macros are utilized to maintain low function-level Cyclomatic Complexity ($\text{CCN} \le 2$).
