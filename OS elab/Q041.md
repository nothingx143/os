## Problem Statement

A and B are playing a game. In this game, both of them are initially provided with a list of $n$ numbers. Both have the same list but their own copy. A picks the element from start of his list. B picks from the end of his list.

Method to be followed at each step to build the output list:
- If number picked by A is bigger than B, output is `1`. B removes the number picked.
- If number picked by A is smaller than B, output is `2`. A removes the number picked.
- If both have the same number, output is `0`. Both A and B remove the number picked.
- The game ends when at least one list gets empty.

### Mandatory Keyword
- `if(a[i]>a[j])`

### Constraints
$1 \le N \le 10^6$  
$1 \le num \le 10^9$

### Input Format
First line: $n$  
Second line: $n$ space-separated integers  

### Output Format
Space-separated sequence of outputs (`1`, `2`, `0`).

## Verified Solution (`Q041.c`)

```c
#include <stdio.h>

int a[1000005];

int main() {
    int n, i = 0, j;
    scanf("%d", &n);
    for (int k = 0; k < n; k++) scanf("%d", &a[k]);
    j = n - 1;
    while (i < n && j >= 0) {
        if(a[i]>a[j]) {
            printf("1 ");
            j--;
        } else if (a[i] < a[j]) {
            printf("2 ");
            i++;
        } else {
            printf("0 ");
            i++;
            j--;
        }
    }
    return 0;
}
```
