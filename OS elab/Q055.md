# Q055: Queue (Level 1 Challenge 55)

## Verified Solution (`Q055.c`)

```c
#include <stdio.h>

char cc[500005];
long long last[128];

int main() {
    scanf("%s", cc);
    long long total = 1, mod = 1000000007;
    int i;
    for(i=0;cc[i];i++) {
        long long cur = total;
        total = (total * 2 - last[(unsigned char)cc[i]] + mod) % mod;
        last[(unsigned char)cc[i]] = cur;
    }
    printf("%lld", (total - 1 + mod) % mod);
    return 0;
}
```

## Problem Statement

You are given a string. You can remove any number of characters from it, but you cannot change the order of the remaining characters.

How many different strings can you generate?

Constraints

1≤n≤5⋅10^5


Input
The first input line contains a string of size n. Each character is one of a–z.

Output
Print one integer: the number of strings modulo 10^9+7.
