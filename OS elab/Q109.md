# Q109: Searching (Level 2 Challenge 9)

## Verified Solution (`Q109.c`)

```c
#include <stdio.h>

long long times[100005];
long long pref[100005];

int lower_bound(long long val, int n) {
    int l = 1, r = n, ans = n + 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (times[mid] >= val) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }
    return ans;
}

int main() {
    int q, type, cnt = 0;
    if (scanf("%d", &q) != 1) return 0;
    while (q--) {
        scanf("%d", &type);
        if (type == 1) {
            long long x, t;
            scanf("%lld %lld", &x, &t);
            cnt++;
            times[cnt] = t;
            pref[cnt] = pref[cnt - 1] + x;
        } else {
            long long k, t;
            scanf("%lld %lld", &k, &t);
            int idx = lower_bound(t - k, cnt);
            if (idx <= cnt) {
                printf("%lld\n", pref[cnt] - pref[idx - 1]);
            } else {
                printf("0\n");
            }
        }
    }
    return 0;
}
```

## Problem Statement

Question description

Today, you've been assigned a challenge similar to those faced by back end developers on a daily basis. You must assist in the processing of a huge number of requests received in a purchasing application.

The following are the characteristics of the application:

Customers use this app to place a huge number of orders.
Each request is assigned a time stamp as well as an order size.
Each order size is calculated in kilogrammes and can only be of integer weight.

The data analytics team now need data at regular intervals. You must assist the data-analytics team in answering all queries given by them based on the requests received in the app. So here's what you have to do:

Given 2 types of queries, the first one being of the form 1 X T, indicates an order of weight X is received at time T. The second one is of the form 2 K T indicates that the data analytics team asks you about the summation of weight of the orders received during the last K minutes at time T. The first query can be of the first type only.

For each query, it is guaranteed that they are given in ascending order of time. It means that given q queries and each query having a time T associated with it, T_i < T_{i+1} < T_{i+2} ... < T_q.

### Constraints
1 <= q <= 10^5  
1 <= T_i <= 10^9  
1 <= X_i <= 10^9  
1 <= K_i <= T_i  

### Input Format
The first line contains a single integer q denoting the total number of queries. Each of the next q lines contains either of the two types of queries. Each query of type 1 first starts with the number 1 followed by 2 integers X and T. Each query of the second type first starts with the integer 2 and is then followed by 2 integers K and T.  

### Output Format
For each query of the second type, you need to print the required answer on a new line.  

### Explanation
Sample Input:  
4  
1 20 3  
1 40 4  
2 5 5  
1 100 100  

Sample Output:  
60  

Explanation:  
Here, you first receive an order of weight 20 at time 3, then an order of weight 40 at time 4. Now, for the third query, you need to find the summation of all orders received from time 0 to time 5, i.e 20 + 40 = 60. Now you finally recieve another order at time 100, but are asked nothing about it.
