# Level 1 Challenge 98: Cheese Factory Storage (Producer-Consumer Problem)

## Verified Solution (`Q098.c`)

```c
#include <stdio.h>

int mutex = 1, full = 0, empty = 3, x = 0, choice;

void producer() {
    --mutex;
    ++full;
    --empty;
    x++;
    printf("Producer produces the item %d\n", x);
    ++mutex;
}

void consumer() {
    --mutex;
    --full;
    ++empty;
    printf("Consumer consumes item %d\n", x);
    x--;
    ++mutex;
}

void handle_produce() {
    if (empty != 0) producer();
    else printf("Buffer is full!!\n");
}

void handle_consume() {
    if (full != 0) consumer();
    else printf("Buffer is empty!!\n");
}

void step(int c) {
    if (c == 1) handle_produce();
    else if (c == 2) handle_consume();
}

int main() {
    while (scanf("%d", &choice) == 1) {
        if (choice == 3) break;
        step(choice);
    }
    return 0;
}
```

---

## Problem Description
Alia runs a cheese producing company with minimum storage capacity (buffer capacity of 3 items). Daily she produces cheese and stores it in her shop:
- If she produces more than the storage capacity, she is unable to store the product (`Buffer is full!!`).
- Once stored in the shop, a consumer can buy the cheese (`Consumer consumes item X`).
- The product count reduces whenever a consumer consumes cheese.
- If there is no cheese in storage, the consumer cannot buy any product (`Buffer is empty!!`).

Menu Operations:
- `1`: Producer produces item
- `2`: Consumer consumes item
- `3`: Exit simulation

## Input Format
Sequence of integer menu choices (`1`, `2`, or `3`) from standard input.

## Output Format
Status and action messages:
- `Producer produces the item X`
- `Consumer consumes item X`
- `Buffer is full!!`
- `Buffer is empty!!`
