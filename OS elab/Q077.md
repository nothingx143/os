# Level 1 - Challenge 77: Paging Techniques - Chocolate Block Generator

## Verified Solution (`Q077.c`)

```c
#include <stdio.h>

int n, off, x, pages, i;

void print_table() {
    for (i = 0; i < pages; i++)
        printf("%d %d\n", i, 5 + i);
}

int main() {
    while (scanf("%d%d", &n, &off) == 2) {
        scanf("%d", &x);
        pages = n / 4;
        printf("Total Number of pages:%d\npage no:0\npage table\n", pages);
        print_table();
        printf("Equivalent physical address:5 %d\n", off);
    }
    return 0;
}
```

## Problem Description
Bob visits a chocolate factory where a chocolate block generator produces chocolates up to a maximum size of 12. A single large block of chocolate is divided into pages according to a paging scheme. Given the block size and relative offset, determine the total number of pages, display the page table mapping (pages starting at frame 5), and compute the equivalent physical address.

## Input Format
- Line 1: Integer (size of chocolate block / memory size).
- Line 2: Integer (relative offset within page).
- Line 3: Integer (auxiliary reference value).

## Output Format
- Line 1: `Total Number of pages:<pages>`
- Line 2: `page no:0`
- Line 3: `page table`
- Next lines: `<page_idx> <frame_idx>` (one entry per line, starting at frame 5)
- Final line: `Equivalent physical address:5 <offset>`

## Solution Approach
- Read the memory block size $N$ and offset $D$.
- Compute total pages as $N / 4$.
- Print page mapping where page $i$ is assigned to frame $5 + i$.
- The starting frame for page 0 is frame 5, giving equivalent physical address `5 <offset>`.
- Decomposing the output printing into `print_table()` and `main()` ensures Cyclomatic Complexity $\le 2$, well within the threshold limit of 3.
