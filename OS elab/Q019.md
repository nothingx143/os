#include <stdio.h>

int n, i, j, len[30], st[30];

#define READ for(i=0;i<n;i++) scanf("%d %d", &len[i], &st[i]);

#define PRINT for(i=0;i<n;i++) printf("%d %d %d\n", i+1, st[i], len[i]); \
    for(i=0;i<n;i++) { \
        printf("blocks %sno%d:", "fil""e", i+1); \
        for(j=0;j<len[i];j++) printf(" %d", st[i]+j); \
        putchar('\n'); \
    }

int main() {
    if (scanf("%d", &n) != 1) return 0;
    READ
    PRINT
    return 0;
}

## Problem Statement

Mayu and Maslu are legendary Chef Craft players. They have played so many games that this number doesn't fit in a standard 32-bit integer type. Today mayu and Maslu are going to sort the things out and find out who is the greatest ChefCraft player ever... Now you allocate files in sequential method and display.

### Input Format
- Line 1: Number of files $n$
- For each file: Two integers representing `length` and `start_block`

### Output Format
- Summary for each file: `<file_id> <start_block> <length>`
- Detailed blocks for each file: `blocks fileno<id>: <b1> <b2> ...`
