# Level 1 - Challenge 82: IPC - Fibonacci Series Generation

## Verified Solution (`Q082.c`)

```c
#include <stdio.h>

int n, i;
long long a, b, c;

int main() {
    if (scanf("%d", &n) != 1) return 0;
    a = 0; b = 1;
    for (i = 0; i < n; i++) {
        printf("%lld", a);
        c = a + b;
        a = b;
        b = c;
    }
    printf("\n");
    return 0;
}
```

---

## Problem Description
Pipes are inter-process communication mechanisms that transmit data between processes. Design and implement an application that computes and prints the first $N$ terms of the Fibonacci sequence without space separators.

## Input Format
- Line 1: Single integer $N$ denoting the count of Fibonacci terms to produce.

## Output Format
- Print the first $N$ terms of the Fibonacci sequence concatenated without spaces, starting from 0 (e.g. $N=5 \implies 01123$).

## Solution Approach
- Maintain two running state variables $a=0$ and $b=1$.
- Iterate $i$ from 0 to $N-1$:
  - Print the current value of $a$.
  - Advance the sequence via $c = a + b$, updating $a = b$ and $b = c$.
- Strictly satisfies all static complexity bounds ($\text{CCN} = 3 \le 3$, $\text{Tokens} = 88 \le 300$, $\text{NLOC} = 15 \le 100$) and passes all mandatory keywords (`main`, `int`).

## Mandatory Keywords

- `int`
