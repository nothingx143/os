# Q108: Searching (Level 2 Challenge 8)

## Verified Solution (`Q108.c`)

```c
#include <stdio.h>
#include <string.h>

int first[200005];
char s[100005];

int main() {
    int n, sum = 0, max_len = 0;
    scanf("%d %s", &n, s);
    memset(first, -1, sizeof(first));
    for(int i=0;i<n;i++) {
        sum += 1 - 2 * (s[i] - '0');
        if (sum > 0) {
            max_len = i + 1;
        } else {
            int p = first[sum - 1 + n];
            if (p != -1) {
                if (i - p > max_len) max_len = i - p;
            }
            if (first[sum + n] == -1) first[sum + n] = i;
        }
    }
    printf("%d\n", max_len);
    return 0;
}
```

## Problem Statement

Question Description:
Murugan has given a string 'S' of length N to Salim. Each character of the string is either 0 or 1. Now, Salim need to select the largest substring in which the count of 0 in the string is more than the count of 1. Can you help to Salim?

### Constraints
1 <= N <= 10^5  

### Input Format
The first line contains an integer N as input.  
The next line contains a string comprising of 0 and 1. The length of this string is exactly N.  

### Output Format
Print the output in a single line contains the length of the largest substring in which the count of 0 is more than 1.  

### Explanation
Sample Input:  
6  
011100  

Sample Output:  
3  

Explanation:  
The last three characters i.e. 100 forms a substring of length 3 which is the largest substring possible in which 0 are more than 1.
