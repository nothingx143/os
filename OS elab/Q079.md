# Level 1 - Challenge 79: Tree 2 - B-sequence Dynamic Insertion

## Problem Description
A sequence $A$ of size $n$ is defined as a B-sequence if it is initially strictly increasing to a unique peak maximum element, and then strictly decreasing. Every element except the maximum can appear at most twice (once in the increasing part and once in the decreasing part), and every element in the decreasing part must already exist in the increasing part. Given an initial B-sequence $S$ and $Q$ insertion queries, insert a given value `val` if and only if the resulting sequence remains a valid B-sequence. Output the size of $S$ after each query, followed by the entire reconstructed sequence $S$ after completing all operations.

## Input Format
- Line 1: Integer $N$ (initial size of $S$).
- Line 2: $N$ space-separated integers representing elements of $S$.
- Line 3: Integer $Q$ (number of operations).
- Next $Q$ lines: Single integer `val` per line.

## Output Format
- After each operation: Print the current size of $S$ on a new line.
- After all operations: Print the full sequence $S$ separated by spaces.

## Solution Approach
- Maintain two sets: `a` for the increasing portion and `b` for the decreasing portion, backed by open-addressing hash tables for $O(1)$ set membership verification.
- For each query `val`:
  - If `val` is not in `a`, insert it into `a`, updating the running maximum `mx`.
  - Else if `val < mx` and `val` is not in `b`, insert it into `b`.
  - Otherwise, `val` cannot be inserted without violating B-sequence invariants.
- At termination, sort `a` ascending and `b` ascending, then append `b` in reverse (descending order) onto `a` and print all elements in a single sequential pass.
- Satisfies all tight static complexity limits ($\text{CCN} \le 5 \le 8$, $\text{Tokens} = 249 \le 275$, $\text{NLOC} = 27 \le 39$) while matching the mandatory keyword `for(i=0;i<N;i++)`.
