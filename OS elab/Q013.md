## Problem Statement

A spacecraft is all set to travel through a long inter-galactic tunnel. The tunnel consists of N stationary space debris. In order to successfully complete the mission the spacecraft needs to destroy all the space debris. The control unit of the spacecraft has M buttons which can be used to destroy the space debris... Find the allocation of file.

### Input Format
A single line containing two space-separated integers: `start_block` ($n_1$) and `length` ($n_2$).

### Output Format
- Each allocated block on its own line: `<block_number> 1`
- Trailing confirmation: `the file is allocated to disk`

## Verified C Solution

```c
#include <stdio.h>

int main() {
    int n1, n2, i;
    if (scanf("%d %d", &n1, &n2) != 2) return 0;
    for (i = n1; i < n1 + n2; i++) printf("%d 1\n", i);
    puts("the file is allocated to disk");
    return 0;
}
```
