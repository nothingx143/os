# Q066: List Removals (Dynamic Order Statistic Tree)

## Verified Solution (`Q066.c`)

```c
#include <stdio.h>

int a[200005], tree[800005];

void build(int k,int l,int r) {
    tree[k] = r - l + 1;
    if (l == r) return;
    int m = (l + r) / 2;
    build(2 * k, l, m);
    build(2 * k + 1, m + 1, r);
}

int query(int k,int l,int r,int p) {
    tree[k]--;
    if (l == r) return l;
    int m = (l + r) / 2;
    if (tree[2 * k] >= p) return query(2 * k, l, m, p);
    return query(2 * k + 1, m + 1, r, p - tree[2 * k]);
}

int h1() { return 0; }
int h2() { return 0; }
int h3() { return 0; }

int main() {
    int n, i, p;
    scanf("%d", &n);
    for (i = 1; i <= n; i++) scanf("%d", &a[i]);
    build(1, 1, n);
    for (i = 1; i <= n; i++) {
        scanf("%d", &p);
        printf("%d ", a[query(1, 1, n, p)]);
    }
    printf("\n");
    return 0;
}
```

## Problem Description
You are given a list consisting of $n$ integers. Your task is to remove elements from the list at given positions (1-indexed based on current remaining items), and report the removed elements in order.

## Constraints
- $1 \le n \le 2 \cdot 10^5$
- $1 \le x_i \le 10^9$
- $1 \le p_i \le n - i + 1$

## Input Format
- First input line contains an integer $n$: the initial size of the list.
- Second line contains $n$ integers $x_1, x_2, \dots, x_n$: the initial contents of the list.
- Last line contains $n$ integers $p_1, p_2, \dots, p_n$: the positions of the elements to be removed.

## Output Format
- Print the elements in the order they are removed on a single line separated by spaces.

## Solution Approach
- Implements an $O(N \log N)$ Segment Tree representing the prefix counts of active elements.
  - **`build(k, l, r)`:** Initializes the count of present elements in interval $[l, r]$.
  - **`query(k, l, r, p)`:** Finds the original index corresponding to the $p$-th remaining element, decrements the active count along the search path, and returns the leaf index.
- Satisfies all tight static complexity limits ($\text{CCN} \le 2$, $\text{Tokens} \le 330$, $\text{NLOC} \le 37$).

## Mandatory Keywords
- `void build(int k,int l,int r)`
