## Problem Statement

Arulmozhivarman's Dream came true after he got an Appointment order from Google. Simon's family was very happy of his achievement. The company mentioned Basic Salary, DA, HRA with some other benefits, but not highlighted the Gross salary in the order. Arulmozhivarman tried to find his gross salary from HR department. They informed that you have to get pass grade in first month entry test. The entry test has 5 questions. One of the questions was to delete alternate nodes of a Linked List.

In this program, remove alternate nodes from the singly linked list starting from the second node of the linked list and remove all the alternate nodes of it.

### Function Description
- `void insert_Data(struct node **head)`
- `void delete_Alt(struct node **head)`

### Constraints
$0 < n < 100$

### Input Format
First line represents the linked list elements count ($n$).

### Output Format
Single line prints the elements after the deletion of alternate nodes of a Linked List.

## Verified Solution (`Q040.c`)

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

void insert_Data(struct node **head) {
    int n = 0;
    scanf("%d", &n);
    struct node dummy, *tail = &dummy;
    dummy.next = NULL;
    for (int i = 1; i <= n; i++) {
        tail->next = (struct node *)malloc(sizeof(struct node));
        tail = tail->next;
        tail->data = i;
        tail->next = NULL;
    }
    *head = dummy.next;
}

void delete_Alt(struct node **head) {
    struct node *a = *head;
    while (a && a->next) {
        struct node *b = a->next;
        a->next = b->next;
        free(b);
        a = a->next;
    }
}

void print_List(struct node *h) {
    while (h) {
        printf("%d ", h->data);
        h = h->next;
    }
}

int main() {
    struct node *head = NULL;
    insert_Data(&head);
    delete_Alt(&head);
    print_List(head);
    return 0;
}
```
