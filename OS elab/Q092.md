# Q092: Hashing (Level 1 Challenge 92)

## Verified Solution (`Q092.c`)

```c
#include <stdio.h>
#include <math.h>

int main() {
    int t;
    scanf("%d", &t);
    double phi = (1.0 + sqrt(5.0)) / 2.0;
    while(t--) {
        long long a, b;
        scanf("%lld %lld", &a, &b);
        long long x = a, y = b;
        if (a > b) { x = b; y = a; }
        long long p = (long long)((y - x) * phi);
        puts(x == p ? "sami" : "canthi");
    }
    return 0;
}
```

## Problem Description
Canthi and Sami are having a game! The game is extremely similar to chess, but there is only one piece on the board, which is the Queen. In addition, the Queen may only go to the top left corner.

For clarification, if the Queen is placed at $(a, b)$, then in a single turn the Queen can move:
1. Any number of cells leftwards.
2. Any number of cells upwards.
3. Any number of cells diagonally (only in the North-West direction).

Please note that the board is quarter-infinite—i.e., there is a top-left corner $(1, 1)$, but it extends infinitely downwards and to the right.

The game is played alternately between Canthi and Sami. A player who cannot make a move loses (the player who moves the Queen to $(1, 1)$ wins). Canthi moves first. Given the starting coordinates $(a, b)$ of the Queen for $T$ test cases, determine whether Canthi or Sami wins assuming both players play optimally.

### Input Format
- First line: An integer $T$ denoting the number of test cases.
- Next $T$ lines: Two space-separated integers $a$ and $b$ denoting the starting position of the Queen.

### Output Format
- For each test case, print `canthi` if Canthi wins, or `sami` if Sami wins on a new line.

## Constraints
- $1 \le T \le 10^5$
- $1 \le a, b \le 10^9$

## Solution Approach
- This is Wythoff's game played on a chessboard with a single queen.
- The losing (cold/P) positions $(x_k, y_k)$ for the first player are given by Beatty sequences with the golden ratio $\phi = \frac{1 + \sqrt{5}}{2} \approx 1.6180339887$:
  $$x_k = \lfloor k \cdot \phi \rfloor, \quad y_k = x_k + k = \lfloor k \cdot \phi^2 \rfloor$$
  where $k = y - x$ (with $x \le y$).
- For any position $(a, b)$, let $x = \min(a, b)$ and $y = \max(a, b)$. If $x = \lfloor (y - x) \cdot \phi \rfloor$, then $(a, b)$ is a cold position, meaning the second player (Sami) wins: output `sami`. Otherwise, Canthi can move to a cold position and win: output `canthi`.
