# Question 95: Hashing - Next Set Bit (Dynamic Sorted Set Lower Bound)

## Problem Description
You are given an array $A$ of length $N$ initialized with 0. Process $Q$ queries of two types:
- `1 k`: Set value 1 at index $k$ in array $A$.
- `2 y`: Print the smallest index $x \ge y$ having value 1. If there is no such index, print `-1`.

## Constraints
- $1 \le n \le 10^9$
- $1 \le q \le 5 \times 10^5$
- $1 \le y, k \le n$

## Solution Approach
- Since $n \le 10^9$, an array or static bitset cannot fit in memory.
- Use an ordered balanced binary search tree (`std::set<int>`) to store the set of active indices.
- For type 1 queries: insert $k$ into the set in $O(\log Q)$ time.
- For type 2 queries: perform `s.lower_bound(y)` in $O(\log Q)$ time. If an element exists, print it; otherwise, print `-1`.
- Total time complexity: $O(Q \log Q)$, with $O(Q)$ space.
