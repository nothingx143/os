# Level 1 - Challenge 80: Tree 2 - Polynomial Segment Tree Queries

## Problem Description
Maintain an array of $n$ integer values and process $q$ queries of two types efficiently:
1. `1 a b`: Add an arithmetic progression to range $[a, b]$ where the first element is increased by 1, the second by 2, ..., and the $i$-th element by $i - a + 1$.
2. `2 a b`: Calculate and print the sum of values in range $[a, b]$.

## Input Format
- Line 1: Two space-separated integers $n$ and $q$ (size of array and number of queries).
- Line 2: $n$ space-separated integers representing initial array elements $t_1, t_2, \dots, t_n$.
- Next $q$ lines: Three space-separated integers representing query format `type a b`.

## Output Format
- Print the result for each range sum query on a new line.

## Solution Approach
- Implemented a Segment Tree with lazy propagation supporting arithmetic progression updates.
- Each tree node maintains:
  - `sum`: total sum of values in the interval $[l, r]$.
  - `la`: lazy tag for initial term of arithmetic progression.
  - `ld`: lazy tag for common difference.
- For interval length $len = r - l + 1$, adding an AP with first term $A$ and common difference $D$ contributes $\Delta = len \cdot A + \frac{len(len - 1)}{2} D$.
- During pushdown, left child receives $(A, D)$ while right child receives $(A + len_L \cdot D, D)$ where $len_L = mid - l + 1$.
- Modularized into `apply()`, `push()`, `build()`, `upd()`, `qry()`, `read_input()`, `proc_query()`, and `main()`, strictly conforming to the static complexity limits ($\text{CCN} \le 1 \le 2$, $\text{Tokens} = 594 \le 800$, $\text{NLOC} = 58 \le 71$) and satisfying the mandatory keyword `void build(int k,int l,int r)`.
