## Problem Statement

There are K tiles. Each of the tiles either contains a single uppercase Latin letter or is a blank tile meaning that it can represent any uppercase Latin letter. Given is also a graph with N nodes and M edges. Initially, some of the nodes contain tiles. The rest of the nodes are unoccupied. Find the sequential letters in order.

### Input Format
- Line 1: Array length $n$
- Line 2: $n$ array elements
- Line 3: Target search element $k$

### Output Format
- Line 1: `Sequential file`
- Line 2: `<k> found at location <pos>` (1-based index) or `<k> is not present in array`

## Verified C Solution

```c
#include <stdio.h>

int num, n, i, g, arr[1005];

#define READ for(i=0;i<num;i++) scanf("%d",&arr[i]); scanf("%d",&n);

#define SEARCH for(i=0;i<num;i++){if(arr[i]==n){g=1;printf("%d found at location %d",n,i+1);break;}} \
    if(!g) printf("%d is not present in array", n);

int main() {
    if (scanf("%d", &num) != 1) return 0;
    puts("Sequential file");
    READ
    SEARCH
    return 0;
}
```
