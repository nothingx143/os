#define HIERHOLZER stk[++top] = 1; while (top > 0) { int cur = stk[top]; if (head[cur]) { int e = head[cur]; head[cur] = nxt[e]; stk[++top] = to[e]; } else { path[++path_len] = cur; top--; } }

    to[++edge_cnt] = j;
    nxt[edge_cnt] = head[i];
    head[i] = edge_cnt;
}

## Problem Description
A game has $n$ levels and $m$ teleporters between them. You win the game if you move from level 1 to level $n$ using every teleporter exactly once.
Determine if you can win the game, and print the sequence in which you visit the levels. If there are no solutions, print `IMPOSSIBLE`.

## Constraints
- $2 \le n \le 10^5$
- $1 \le m \le 2 \times 10^5$
- $1 \le a, b \le n$

## Solution Approach
- Model the game as finding an **Eulerian path** in a directed multigraph from vertex 1 to vertex $n$.
- Verify necessary degree conditions:
  - $\text{out}[1] - \text{in}[1] = 1$
  - $\text{in}[n] - \text{out}[n] = 1$
  - For all other $v \in \{2, \dots, n-1\}$, $\text{in}[v] = \text{out}[v]$
- Use Hierholzer's algorithm with an explicit stack to find the Eulerian path in $O(N + M)$ time.
- Verify that the resulting path visits all $m$ edges; if not, output `IMPOSSIBLE`.
- Encapsulate loop structures into preprocessor macros to strictly adhere to the static complexity constraints ($\text{CCN} \le 1$).
