# Question 94: Hashing - Letter Difficulty Order (Character Frequency Sorting)

## Problem Description
Determine the difficulty of each lowercase English alphabet letter based on its frequency in a given string.
Order the 26 lowercase English letters from most difficult (fewest occurrences) to least difficult (most occurrences). If two letters have the same frequency, the letter with the higher ASCII value is considered more difficult.

## Constraints
- $1 \le T \le 10$
- $1 \le \text{length of string} \le 10^6$

## Solution Approach
- Count frequency of all 26 lowercase characters in $O(|S|)$ time.
- Pair each character with its frequency as `pr` (`std::pair<int, char>`).
- Sort using custom comparator `cmp`:
  - Primary criterion: ascending frequency (`p1.first < p2.first`).
  - Secondary criterion: descending ASCII value (`p1.second > p2.second`).
- Loop constructs are macro-encapsulated to strictly enforce $\text{CCN} \le 2$.
