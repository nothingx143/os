# Challenge 59: Queue - Circular Queue using Linked List and Dequeue Operation

## Problem Description
On the last day of the semester, Shahid's students were talking and playing loudly. To engage them productively, Shahid gave them a task to implement a Circular Queue using a singly linked list and perform dequeue operations twice, printing the queue contents at each step.

A circular queue implemented using a linked list is identical to a circular linked list with two pointers (`front` and `rear`), where `rear->next` points back to `front`.

### Input Format
- First line indicates the size of the queue $N$.
- Second line indicates the $N$ space-separated elements to enqueue into the circular queue.

### Output Format
- Line 1: Circular queue elements after all initial insertions.
- Line 2: Circular queue elements after 1st dequeue operation.
- Line 3: Circular queue elements after 2nd dequeue operation.

## Solution (C)
```c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node* next;
};

struct node *f = NULL;
struct node *r = NULL;

void enqueue(int d) {
    struct node* n;
    n = (struct node*)malloc(sizeof(struct node));
    n->data = d;
    n->next = NULL;
    if (f == NULL) {
        f = r = n;
        r->next = f;
    } else {
        r->next = n;
        r = n;
        n->next = f;
    }
}

void dequeue() {
    if (f == NULL) return;
    if (f == r) {
        free(f);
        f = r = NULL;
    } else {
        struct node* temp = f;
        f = f->next;
        r->next = f;
        free(temp);
    }
}

void display() {
    struct node* t;
    t = f;
    if (f == NULL) return;
    do {
        printf("%d ", t->data);
        t = t->next;
    } while (t != f);
    printf("\n");
}

int main() {
    int n, d;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &d);
        enqueue(d);
    }
    display();
    dequeue();
    display();
    dequeue();
    display();
    return 0;
}
```
